Little Life World — GitHub Pages starter

Publish:
1. Create/sign in to GitHub.
2. Create a new PUBLIC repository named little-life-world.
3. Upload index.html from this folder (or upload the ZIP contents).
4. In repository Settings > Pages, choose Deploy from a branch.
5. Select main branch and /(root), then Save.
6. Wait for GitHub Pages to publish; your URL will be https://YOUR-USERNAME.github.io/little-life-world/

This is an experimental 3D starter, not a finished Sims-like game. It imports Three.js from a CDN and needs internet access.
